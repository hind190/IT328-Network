# Image Challenge Game | Computer Networks

A multiplayer image puzzle game developed using Java Socket Programming and Swing GUI.

## Features
- Real-time client-server communication
- Multiple player connections
- Waiting room system
- Connected players list
- Interactive GUI design

## Technologies Used
- Java
- Java Sockets
- Swing GUI
- Multithreading

## How to Run
1. Run the Server
2. Run one or more Clients
3. Enter username and connect
4. Join the waiting room and play
